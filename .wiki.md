# Project Summary
The Peaceful Game Village project is a web-based platform designed to connect novice gamers with experienced mentors across popular games like Overwatch, PUBG, and Valorant. The platform aims to enhance community engagement and learning through features such as user authentication, mentor management, personalized application tracking, and a feedback system for students to rate their mentors. Recent updates have focused on improving the login system, user interface, analytics for tracking submissions, and streamlining user registration.

# Project Module Description
- **Frontend**: Developed using React and TypeScript, styled with Tailwind CSS. It includes pages for class selection, teacher profiles, application forms, an admin dashboard, and a personalized "My Page" for tracking applications. The frontend features engaging game-themed cards and a simplified navigation system, with a review system excluding star ratings.
- **Backend**: Built on Atoms Cloud for user authentication and database management, supporting CRUD operations for teachers and applications. This module manages batch processing for teacher data, tracks current student counts, application statuses, and maintains an activity log for admin actions. Recent enhancements include a new login endpoint and a registration endpoint to improve the authentication process.

# File Description Inventory
- **app/backend/**: Contains backend logic, including authentication, database models, and API routes.
- **app/frontend/**: Contains frontend application files, including components, pages, and styling.
- **app/assets/**: Contains image assets used in the application.
- **app/frontend/src/pages/Login.tsx**: Login page for user authentication using username and password.
- **app/frontend/src/pages/ApplicationForm.tsx**: Form for submitting applications, now redirects to MyPage after submission.
- **app/frontend/src/pages/MyPage.tsx**: Displays assigned teacher info, user reviews, graduation interview status, and user game ID and Discord ID. Recently updated to correctly fetch the current user's applications.
- **app/frontend/src/pages/Signup.tsx**: Page for new user registration, updated to connect to the new backend registration endpoint.
- **app/frontend/src/pages/admin/AdminApplications.tsx**: Admin page for managing student applications.
- **app/frontend/src/pages/admin/Dashboard.tsx**: Admin dashboard updated to include new monthly application statistics chart.
- **app/frontend/src/pages/ApplicationComplete.tsx**: Confirmation page after application submission.
- **app/backend/routers/members.py**: Updated to include a new `/register` endpoint for user registration.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, lucide-react, canvas-confetti, recharts
- **Backend**: Atoms Cloud (for authentication and database), PostgreSQL
- **Deployment**: Managed through pnpm for package management.

# Usage
1. **Install Dependencies**: 
   - Navigate to the frontend directory and run `pnpm install` to install the required packages.
2. **Build the Project**: 
   - Run `pnpm run build` to compile the frontend application.
3. **Run the Application**: 
   - Use the respective commands to start the backend and frontend servers.
