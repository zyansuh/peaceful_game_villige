# Project Summary
The Peaceful Game Village project is a web-based platform that connects novice gamers with experienced mentors in popular games like Overwatch, PUBG, and Valorant. This platform promotes community engagement and enhances learning through features such as user authentication, mentor management, personalized application tracking, and a feedback system for students to evaluate their mentors. Recent developments have focused on refining the login system, enhancing the user interface, and managing graduation interviews and application statuses. The latest updates include adding edit and delete functionalities for admin applications and interviews.

# Project Module Description
- **Frontend**: Developed using React and TypeScript, styled with Tailwind CSS. It includes pages for class selection, teacher profiles, application forms, an admin dashboard, and a personalized "My Page" for tracking applications. The frontend features engaging game-themed cards, a simplified navigation system, and a review system excluding star ratings.
- **Backend**: Built on Atoms Cloud for user authentication and database management, supporting CRUD operations for teachers and applications. This module manages batch processing for teacher data, tracks student counts, application statuses, and maintains an activity log for admin actions. Recent enhancements include new endpoints for login and registration to improve the authentication process.

# File Description Inventory
- **app/backend/**: Contains backend logic, including authentication, database models, and API routes.
- **app/frontend/**: Contains frontend application files, including components, pages, and styling.
- **app/assets/**: Contains image assets used in the application.
- **app/frontend/src/pages/Login.tsx**: Login page for user authentication using username and password.
- **app/frontend/src/pages/ApplicationForm.tsx**: Form for submitting applications, redirects to MyPage after submission.
- **app/frontend/src/pages/MyPage.tsx**: Displays assigned teacher info, user reviews, graduation interview status, and user game ID and Discord ID.
- **app/frontend/src/pages/GraduationInterview.tsx**: Page for managing graduation interviews, utilizing updated SDK methods for querying and updating interview data.
- **app/frontend/src/pages/Signup.tsx**: Page for new user registration, connects to the backend registration endpoint.
- **app/frontend/src/pages/admin/AdminApplications.tsx**: Admin page for managing student applications, now includes edit and delete functionalities.
- **app/frontend/src/pages/admin/AdminInterviews.tsx**: Admin page for managing graduation interviews, now includes edit and delete functionalities.
- **app/frontend/src/pages/admin/Dashboard.tsx**: Admin dashboard includes new monthly application statistics chart and links to manage interviews and other admin tasks.
- **app/frontend/src/pages/ApplicationComplete.tsx**: Confirmation page after application submission.
- **app/frontend/src/pages/TeacherDetail.tsx**: New page that checks if a user has an existing application and displays relevant information based on the application status.
- **app/backend/routers/members.py**: Updated to include a new `/register` endpoint for user registration.
- **app/frontend/src/components/AdminLayout.tsx**: New layout component for admin pages, integrating the sidebar and main content area.
- **app/frontend/src/components/AdminSidebar.tsx**: New sidebar component for navigation within the admin section.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, lucide-react, canvas-confetti, recharts
- **Backend**: Atoms Cloud (for authentication and database), PostgreSQL
- **Deployment**: Managed through pnpm for package management.

# Usage
1. **Install Dependencies**: 
   - Navigate to the frontend directory and run `pnpm install` to install the required packages.
2. **Build the Project**: 
   - Run `pnpm run build` to compile the frontend application.
3. **Run the Application**: 
   - Use the respective commands to start the backend and frontend servers.
