# Project Summary
The Peaceful Game Village project is a web-based platform that facilitates teacher assignments within a gaming community. It connects new members with mentor teachers across popular gaming titles such as Overwatch, PUBG, and Valorant. The platform enhances user engagement with features like user authentication, teacher management, and student applications. Recent updates include a redesigned main page with visually appealing game-themed cards and a personalized "My Page." The latest iteration has streamlined functionalities for managing teacher data, ensuring a seamless experience for both students and educators.

# Project Module Description
- **Frontend**: Developed using React and TypeScript, styled with Tailwind CSS. It includes pages for class selection, teacher profiles, application forms, an admin dashboard, and a personalized "My Page" for tracking applications. Key functionalities include large background-style cards and celebratory animations.
- **Backend**: Built on Atoms Cloud for user authentication and database management, supporting CRUD operations for teachers and applications. It also includes batch processing features for teacher data.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, lucide-react, canvas-confetti
- **Backend**: Atoms Cloud (for authentication and database), PostgreSQL
- **Deployment**: Managed through pnpm for package management.

# Usage
1. **Install Dependencies**: 
   - Navigate to the frontend directory and run `pnpm install` to install the required packages.
2. **Build the Project**: 
   - Run `pnpm run build` to compile the frontend application.
3. **Run the Application**: 
   - Use the respective commands to start the backend and frontend servers.
