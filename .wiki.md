# Project Summary
The Peaceful Game Village project is a web-based platform aimed at enhancing the gaming community experience by connecting new members with mentor teachers across popular gaming titles like Overwatch, PUBG, and Valorant. It facilitates user engagement through features such as user authentication, teacher management, and personalized application tracking. Recent updates have included a revamped main page, improved user interface, real-time updates for teacher data management, and game-specific banner images. A new password protection feature has been added to safeguard the admin functionalities.

# Project Module Description
- **Frontend**: Developed using React and TypeScript, styled with Tailwind CSS. It includes pages for class selection, teacher profiles, application forms, an admin dashboard, and a personalized "My Page" for tracking applications. Notable features include visually appealing game-themed cards and improved navigation.
- **Backend**: Built on Atoms Cloud for user authentication and database management, supporting CRUD operations for teachers and applications. It includes batch processing features for teacher data and manages the `current_students` count and application statuses.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, lucide-react, canvas-confetti
- **Backend**: Atoms Cloud (for authentication and database), PostgreSQL
- **Deployment**: Managed through pnpm for package management.

# Usage
1. **Install Dependencies**: 
   - Navigate to the frontend directory and run `pnpm install` to install the required packages.
2. **Build the Project**: 
   - Run `pnpm run build` to compile the frontend application.
3. **Run the Application**: 
   - Use the respective commands to start the backend and frontend servers.
