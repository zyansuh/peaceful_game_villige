# Project Summary
The Peaceful Game Village project is a web-based platform designed to connect novice gamers with experienced mentors in popular games like Overwatch, PUBG, and Valorant. This initiative enhances community engagement and learning by providing user authentication, mentor management, personalized application tracking, and a feedback system for students to evaluate their mentors. Recent updates have focused on improving the login system, user interface, analytics for tracking submissions, and streamlining user registration, while also introducing functionalities for managing graduation interviews and checking existing applications.

# Project Module Description
- **Frontend**: Developed using React and TypeScript, styled with Tailwind CSS. It features pages for class selection, teacher profiles, application forms, an admin dashboard, and a personalized "My Page" for tracking applications. The frontend includes engaging game-themed cards, a simplified navigation system, and a review system excluding star ratings.
- **Backend**: Built on Atoms Cloud for user authentication and database management, supporting CRUD operations for teachers and applications. This module manages batch processing for teacher data, tracks student counts, application statuses, and maintains an activity log for admin actions. Recent enhancements include a new login endpoint and a registration endpoint to improve the authentication process.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, lucide-react, canvas-confetti, recharts
- **Backend**: Atoms Cloud (for authentication and database), PostgreSQL
- **Deployment**: Managed through pnpm for package management.

# Usage
1. **Install Dependencies**: 
   - Navigate to the frontend directory and run `pnpm install` to install the required packages.
2. **Build the Project**: 
   - Run `pnpm run build` to compile the frontend application.
3. **Run the Application**: 
   - Use the respective commands to start the backend and frontend servers.
