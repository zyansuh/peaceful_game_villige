# Project Summary
The Peaceful Game Village project is a web-based teacher assignment system tailored for a gaming community. It connects new members with mentor teachers across three gaming classes: Overwatch, PUBG, and Valorant. This platform enhances user engagement through features such as user authentication, teacher management, and student applications. Recent updates have introduced a cancel application feature, celebratory animations, and a personalized "My Page" for tracking application statuses. The main page has been redesigned with visually appealing background-style cards featuring class-specific animal silhouettes, and now includes a slide-up text animation effect for class names on hover.

# Project Module Description
- **Frontend**: Developed using React and TypeScript, styled with Tailwind CSS. It includes pages for class selection, teacher details, application forms, an admin dashboard, and a "My Page" for users to monitor their applications. Enhancements include large background-style cards, position and tier filters, sorting dropdowns on the ClassPage, confetti animations on the ApplicationComplete page, and hover animations for class names.
- **Backend**: Utilizes Atoms Cloud for user authentication and database management, supporting CRUD operations for teachers and applications.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, lucide-react, canvas-confetti
- **Backend**: Atoms Cloud (for authentication and database), PostgreSQL
- **Deployment**: Managed through pnpm for package management.

# Usage
1. **Install Dependencies**: 
   - Navigate to the frontend directory and run `pnpm install` to install the required packages.
2. **Build the Project**: 
   - Run `pnpm run build` to compile the frontend application.
3. **Run the Application**: 
   - Use the respective commands to start the backend and frontend servers.
