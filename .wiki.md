# Project Summary
The Peaceful Game Village project is a web-based teacher assignment system designed for a gaming community. It connects new members with mentor teachers across popular gaming titles, including Overwatch, PUBG, and Valorant. The platform enhances user engagement through features like user authentication, teacher management, and student applications. Recent updates include a redesigned main page with visually appealing game-themed cards, larger class names, and silhouette-style mascot icons, as well as animated application statuses and a personalized "My Page" for users. The latest iteration introduces a new Valorant-themed banner, enriching the visual appeal of the application.

# Project Module Description
- **Frontend**: Built with React and TypeScript, styled using Tailwind CSS. It features pages for class selection, teacher profiles, application forms, an admin dashboard, and a personalized "My Page" for tracking applications. Key functionalities include large background-style cards, position and tier filters, sorting dropdowns, and celebratory animations.
- **Backend**: Developed on Atoms Cloud for user authentication and database management, supporting CRUD operations for teachers and applications.

# File Description Inventory
- **app/backend/**: Contains all backend logic, including authentication, database models, and API routes.
- **app/frontend/**: Contains the frontend application files, including components, pages, and styling.
- **app/assets/**: Contains image assets used in the application.
- **app/frontend/src/pages/Index.tsx**: Main page layout featuring silhouette-style mascot icons, larger game names, and redesigned game-themed cards, including the new Valorant fox banner image.
- **app/frontend/image_manifest.json**: Updated to reflect new assets for the frontend, including the latest images.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, lucide-react, canvas-confetti
- **Backend**: Atoms Cloud (for authentication and database), PostgreSQL
- **Deployment**: Managed through pnpm for package management.

# Usage
1. **Install Dependencies**: 
   - Navigate to the frontend directory and run `pnpm install` to install the required packages.
2. **Build the Project**: 
   - Run `pnpm run build` to compile the frontend application.
3. **Run the Application**: 
   - Use the respective commands to start the backend and frontend servers.
