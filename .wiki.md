# Project Summary
The Peaceful Game Village project is a web-based teacher assignment system designed specifically for a gaming community. It enables new members to select mentor teachers across three game classes: Overwatch, PUBG, and Valorant. The platform enhances user experience through features such as user authentication, teacher management, and student applications, ensuring seamless interactions between teachers and students. Recent updates have improved the interface with new filtering and sorting options.

# Project Module Description
- **Frontend**: Developed using React and TypeScript with Tailwind CSS for styling. It includes pages for class selection, teacher details, application forms, and an admin dashboard. New features include position filters, tier filters, and sorting dropdowns on the ClassPage, alongside a blinking badge for teacher cards and a progress bar for student capacity.
- **Backend**: Powered by Atoms Cloud for user authentication and database management, facilitating CRUD operations for teachers and applications.

# File Description Inventory
- **app/backend/**: Contains all backend logic, including authentication, database models, and API routes.
- **app/frontend/**: Contains the frontend application files, including components, pages, and styling.
- **app/assets/**: Contains image assets used in the application.
- **app/frontend/src/index.css**: Updated to include custom animations for UI elements.
- **app/frontend/src/pages/ClassPage.tsx**: Enhanced with position filters, tier filters, and sorting options for teacher cards.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, lucide-react
- **Backend**: Atoms Cloud (for authentication and database), PostgreSQL
- **Deployment**: Managed through pnpm for package management.

# Usage
1. **Install Dependencies**: 
   - Navigate to the frontend directory and run `pnpm install` to install the required packages.
2. **Build the Project**: 
   - Run `pnpm run build` to compile the frontend application.
3. **Run the Application**: 
   - Use the respective commands to start the backend and frontend servers.
