# Project Summary
The Peaceful Game Village project is a web-based platform aimed at enhancing the gaming community by connecting novice gamers with experienced mentors across popular games like Overwatch, PUBG, and Valorant. The platform promotes user engagement through features such as user authentication, teacher management, personalized application tracking, and a feedback system for students to rate their teachers. Recent enhancements include a refreshed main page, an improved user interface, real-time teacher data management, game-specific banner images, and a graduation interview feature that allows students to submit and edit their interview responses.

# Project Module Description
- **Frontend**: Developed with React and TypeScript, styled using Tailwind CSS. It includes pages for class selection, teacher profiles, application forms, an admin dashboard, and a personalized "My Page" for tracking applications. Features visually appealing game-themed cards, improved navigation, and a review system without star ratings.
- **Backend**: Built on Atoms Cloud for user authentication and database management, supporting CRUD operations for teachers and applications. It includes batch processing for teacher data and manages the `current_students` count, application statuses, and an activity log for admin actions.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, lucide-react, canvas-confetti
- **Backend**: Atoms Cloud (for authentication and database), PostgreSQL
- **Deployment**: Managed through pnpm for package management.

# Usage
1. **Install Dependencies**: 
   - Navigate to the frontend directory and run `pnpm install` to install the required packages.
2. **Build the Project**: 
   - Run `pnpm run build` to compile the frontend application.
3. **Run the Application**: 
   - Use the respective commands to start the backend and frontend servers.
