# Project Summary
The Peaceful Game Village project is a web-based teacher assignment system designed for a gaming community. It connects new members with mentor teachers across popular gaming titles, such as Overwatch, PUBG, and Valorant. The platform enhances user engagement through features like user authentication, teacher management, and student applications. Recent updates include a redesigned main page with visually appealing game-themed cards, larger class names, silhouette-style mascot icons, animated application statuses, and a personalized "My Page." The latest iteration also introduces new functionalities for managing teacher data, ensuring a seamless experience for both students and educators.

# Project Module Description
- **Frontend**: Developed using React and TypeScript, styled with Tailwind CSS. It includes pages for class selection, teacher profiles, application forms, an admin dashboard, and a personalized "My Page" for tracking applications. Key functionalities include large background-style cards, position and tier filters, sorting dropdowns, and celebratory animations.
- **Backend**: Built on Atoms Cloud for user authentication and database management, supporting CRUD operations for teachers and applications. It also includes a new feature for batch processing teacher data.

- **app/frontend/src/pages/ClassPage.tsx**: Updated to display teacher cards with new fields including teaching style, personality, active time, and more.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, lucide-react, canvas-confetti
- **Backend**: Atoms Cloud (for authentication and database), PostgreSQL
- **Deployment**: Managed through pnpm for package management.

# Usage
1. **Install Dependencies**: 
   - Navigate to the frontend directory and run `pnpm install` to install the required packages.
2. **Build the Project**: 
   - Run `pnpm run build` to compile the frontend application.
3. **Run the Application**: 
   - Use the respective commands to start the backend and frontend servers.
