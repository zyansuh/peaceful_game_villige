# Project Summary
The Peaceful Game Village project is a web-based platform designed to connect novice gamers with experienced mentors across popular games such as Overwatch, PUBG, and Valorant. The platform enhances the gaming community through user engagement features including user authentication, teacher management, personalized application tracking, and a feedback system for students to rate their teachers. Recent updates have introduced a graduation interview completion page with celebratory animations and a refined user interface.

# Project Module Description
- **Frontend**: Built with React and TypeScript, styled using Tailwind CSS. It includes pages for class selection, teacher profiles, application forms, an admin dashboard, and a personalized "My Page" for tracking applications. The frontend features visually appealing game-themed cards, improved navigation, and a review system without star ratings.
- **Backend**: Developed on Atoms Cloud for user authentication and database management, supporting CRUD operations for teachers and applications. This module handles batch processing for teacher data, manages the `current_students` count, application statuses, and an activity log for admin actions.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, lucide-react, canvas-confetti
- **Backend**: Atoms Cloud (for authentication and database), PostgreSQL
- **Deployment**: Managed through pnpm for package management.

# Usage
1. **Install Dependencies**: 
   - Navigate to the frontend directory and run `pnpm install` to install the required packages.
2. **Build the Project**: 
   - Run `pnpm run build` to compile the frontend application.
3. **Run the Application**: 
   - Use the respective commands to start the backend and frontend servers.
