# Project Summary
The Peaceful Game Village project is a web-based teacher assignment system designed for a gaming community. It effectively connects new members with mentor teachers across three gaming classes: Overwatch, PUBG, and Valorant. The platform enhances user engagement with features such as user authentication, teacher management, and student applications. Recent updates have introduced a more visually appealing main page with redesigned cards featuring game-themed backgrounds, larger class names, and always-visible class labels. Additional features include animations for application statuses and a personalized "My Page" for users.

# Project Module Description
- **Frontend**: Built using React and TypeScript, styled with Tailwind CSS. It includes pages for class selection, teacher details, application forms, an admin dashboard, and a "My Page" for users to track their applications. Enhancements include large background-style cards, position and tier filters, sorting dropdowns, and celebratory animations.
- **Backend**: Utilizes Atoms Cloud for user authentication and database management, supporting CRUD operations for teachers and applications.

# File Description Inventory
- **app/backend/**: Contains all backend logic, including authentication, database models, and API routes.
- **app/frontend/**: Contains the frontend application files, including components, pages, and styling.
- **app/assets/**: Contains image assets used in the application.
- **app/frontend/src/pages/Index.tsx**: Updated to feature larger game names, always-visible class names, and redesigned game-themed cards.
- **app/frontend/image_manifest.json**: Updated to reflect new assets for the frontend.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, lucide-react, canvas-confetti
- **Backend**: Atoms Cloud (for authentication and database), PostgreSQL
- **Deployment**: Managed through pnpm for package management.

# Usage
1. **Install Dependencies**: 
   - Navigate to the frontend directory and run `pnpm install` to install the required packages.
2. **Build the Project**: 
   - Run `pnpm run build` to compile the frontend application.
3. **Run the Application**: 
   - Use the respective commands to start the backend and frontend servers.
