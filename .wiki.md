# Project Summary
The Peaceful Game Village project is a web-based teacher assignment system tailored for a gaming community. It allows new members to select mentor teachers across three game classes: Overwatch, PUBG, and Valorant. The platform enhances user experience through features such as user authentication, teacher management, and student applications, ensuring seamless interactions between teachers and students. Recent updates have introduced celebratory animations and improved teacher summary displays upon application completion.

# Project Module Description
- **Frontend**: Developed using React and TypeScript with Tailwind CSS for styling. It includes pages for class selection, teacher details, application forms, and an admin dashboard. New features include position filters, tier filters, sorting dropdowns on the ClassPage, and a confetti animation on the ApplicationComplete page to enhance user engagement.
- **Backend**: Powered by Atoms Cloud for user authentication and database management, facilitating CRUD operations for teachers and applications.

# File Description Inventory

- **app/frontend/src/pages/ClassPage.tsx**: Enhanced with position filters, tier filters, and sorting options for teacher cards.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, lucide-react, canvas-confetti
- **Backend**: Atoms Cloud (for authentication and database), PostgreSQL
- **Deployment**: Managed through pnpm for package management.

# Usage
1. **Install Dependencies**: 
   - Navigate to the frontend directory and run `pnpm install` to install the required packages.
2. **Build the Project**: 
   - Run `pnpm run build` to compile the frontend application.
3. **Run the Application**: 
   - Use the respective commands to start the backend and frontend servers.
