# Project Summary
The Peaceful Game Village project is a web-based platform designed to connect novice gamers with experienced mentors across popular games such as Overwatch, PUBG, and Valorant. It aims to enhance community engagement through features like user authentication, mentor management, personalized application tracking, and a feedback system for students to rate their mentors. Recent updates include a new login system, an improved user interface, and enhanced analytics for monitoring interview submissions, along with a new registration endpoint for user signups.

# Project Module Description
- **Frontend**: Developed with React and TypeScript, styled with Tailwind CSS. It includes pages for class selection, teacher profiles, application forms, an admin dashboard, and a personalized "My Page" for tracking applications. The frontend features visually engaging game-themed cards, streamlined navigation, and a review system without star ratings.
- **Backend**: Built on Atoms Cloud for user authentication and database management, supporting CRUD operations for teachers and applications. This module manages batch processing for teacher data, tracks `current_students` counts, application statuses, and maintains an activity log for admin actions. A new member-login endpoint and a registration endpoint have been added to enhance the authentication process.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, lucide-react, canvas-confetti, recharts
- **Backend**: Atoms Cloud (for authentication and database), PostgreSQL
- **Deployment**: Managed through pnpm for package management.

# Usage
1. **Install Dependencies**: 
   - Navigate to the frontend directory and run `pnpm install` to install the required packages.
2. **Build the Project**: 
   - Run `pnpm run build` to compile the frontend application.
3. **Run the Application**: 
   - Use the respective commands to start the backend and frontend servers.
